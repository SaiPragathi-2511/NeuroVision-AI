## 🚀 About
NeuroVision-AI is an AI-powered platform for brain tumor detection from MRI scans. 
- Accuracy: 96.8%
- Scans Today: 87
- Avg Time: 2.1s per analysis

## ✨ Features
- 📤 Upload MRI Scan (DICOM, NIfTI, PNG, JPG)
- 🎯 Detects 4 Tumor Types: Glioma, Meningioma, Pituitary, No Tumor
- 📊 Confidence Scores & Classification
- 🧾 Symptoms & Treatment Recommendations
- 🖼️ MRI Scan Gallery with Analysis

## 🛠️ Tech Stack
HTML5, CSS3, JavaScript, EfficientNet-B4 Model

## 📥 How to Use
1. Upload MRI image
2. AI analyzes in 2.1s
3. Get report with confidence, symptoms, treatment
